# Yuka Store Web

Landing page Yuka Store — Shop & Service, spesialis iPhone baru & second di Garut.
SvelteKit + Tailwind + Bun, siap deploy ke Vercel.

## Develop

```sh
bun install
bun run dev --open
```

## Build

```sh
bun run build
bun run preview
```
